# Lista de Convites de Aniversário — Cloudflare Pages

Aplicativo web responsivo para cadastrar evento, convidados, quantidade de pessoas, confirmações e enviar convites pelo WhatsApp.

## Cloudflare Pages
Configuração:
- Branch: main
- Root directory: lista-convites-aniversario
- Framework preset: None
- Build command: vazio
- Build output directory: public

Depois crie um KV Namespace e adicione um binding com nome exato STATE.
