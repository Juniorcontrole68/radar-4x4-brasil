# Lista de Convites - Android / Google Play

Pacote Android: `com.oswaldo.listaconvites`
Site/TWA: `https://lista-de-aniversario-jr.onrender.com/`
Target SDK: 35
Versão inicial: 1.0.0 (versionCode 1)

## Estado atual
- Projeto Android/TWA criado.
- Workflow do GitHub gera APK e AAB de teste.
- Para envio à Play Store ainda é necessário criar e guardar uma chave de upload de produção.
- Depois da chave de produção, publicar `/.well-known/assetlinks.json` com o SHA-256 do certificado para a TWA abrir sem barra do navegador.
- Não versionar a chave de assinatura no GitHub.

## Play Console
Para conta pessoal criada após 13/11/2023, o Google exige teste fechado com pelo menos 12 testadores por 14 dias antes de solicitar acesso à produção.
