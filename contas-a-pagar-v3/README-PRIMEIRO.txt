CONTAS A PAGAR v3

Este e um aplicativo WEB, por isso nao existe arquivo .EXE.

ARQUIVOS IMPORTANTES:
- server.js: inicia o servidor
- src/: logica do servidor e banco
- public/: interface visual (CSS e JavaScript)
- database/schema.sql: estrutura do banco
- render.yaml: configuracao para publicacao no Render
- .env.example: modelo de configuracao do banco
- INICIAR_WINDOWS.bat: inicializacao local no Windows

Para usar no Render, publique todos estes arquivos no GitHub e configure DATABASE_URL com o PostgreSQL permanente.
